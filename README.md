# 🐰 Happy Word Adventure

เว็บเกมเรียนคำศัพท์ภาษาอังกฤษแบบ **เล่นเพลิน** สำหรับเด็กอายุ 4–5 ปี
Static site ล้วน — ไม่มีฐานข้อมูล ไม่มี backend ไม่ต้อง build

**เล่นได้ที่:** _(ใส่ URL หลัง deploy)_

## สิ่งที่มีในเวอร์ชันนี้

| โหมด | รายละเอียด |
|---|---|
| 🎪 **เล่นเพลิน** | แตะสัตว์ → กระโดด/ส่ายหัว/หมุน + ออกเสียงชื่อ · แตะค้างพูดเป็นประโยค · ไม่มีคำถาม ไม่มีถูกผิด |
| 📖 **การ์ดคำศัพท์** | เรียนทีละ 3 คำ · ฟังซ้ำได้ไม่จำกัด · ย้อนกลับได้ |
| 🎮 **เกมทายรูป** | 5 ข้อ พร้อม **No-Fail System** — ตอบผิดได้ไม่จำกัด ระบบค่อย ๆ ช่วยจนถูก |
| 🎉 **หน้าสรุป** | ดาวขึ้นทีละดวง + confetti + ปลดล็อกสัตว์ |
| 🏡 **สวนสัตว์** | ดูสัตว์ที่สะสมได้ แตะฟังเสียงซ้ำ |

### เกมทั้งหมด (หน้า 🎯 เลือกเกม)

| เกม | วิธีเล่น | ทักษะ | ไฟล์ |
|---|---|---|---|
| 🐶 จับคู่สัตว์ | ลากสัตว์ไปวางทับคู่ของมัน | การสังเกต | `games/dragmatch.js` |
| 🎨 สีอะไรเอ่ย | โจทย์บอกสี แตะของที่เป็นสีนั้น | เรียนรู้สี | `games/colorgame.js` |
| 🔢 นับผลไม้ | แตะนับทีละลูก แล้วเลือกตัวเลข | การนับ 1–10 | `games/countgame.js` |
| 🧩 ต่อภาพสัตว์ | ลากชิ้นส่วนมาต่อเป็นภาพ (2×2 → 3×3) | คิดเชิงพื้นที่ | `games/puzzle.js` |
| 🐰 ช่วยกระต่ายกลับบ้าน | ลาก/แตะพากระต่ายผ่านเขาวงกต เก็บแครอท | ควบคุมมือ | `games/maze.js` |
| ⭐ เก็บดาว | แตะดาวที่โผล่ขึ้นมาให้ครบ | สมาธิ | `games/starcatch.js` |
| 🐠 ให้อาหารปลา | เลือกอาหารสีเดียวกับปลาที่หิว | การจำแนก | `games/feedfish.js` |
| 🚗 รถสีเดียวกัน | ลากรถไปจอดช่องสีเดียวกัน | สี + การลาก | `games/carpark.js` |
| 🧠 จำอะไรหายไป | ดูของ 3–5 ชิ้น ปิดผ้า เอาออก 1 ชิ้น แล้วทาย | ความจำ | `games/missing.js` |
| 🎈 ลูกโป่งตัวเลข | กดลูกโป่งตามลำดับ 1 → 2 → 3 … | ลำดับตัวเลข | `games/balloons.js` |
| 🎮 ทายรูปสัตว์ | เรียนการ์ด 3 คำ แล้วตอบ 5 ข้อ | คำศัพท์ | `app.js` |
| 🃏 จับคู่ภาพสัตว์ | เปิดการ์ดหาคู่ที่เหมือนกัน | ความจำ | `app.js` |

ทุกเกมใช้กติกาเดียวกัน: **ไม่มีเวลาจับ · ไม่มีคำว่าผิด · ไม่มีการหักดาว** ตอบผิดจะค่อย ๆ ได้คำใบ้จนถูก และได้ดาวเท่ากันเสมอ

**เทคนิคที่ใส่ไว้แล้ว**

- ✅ ปลดล็อก AudioContext ด้วยหน้า "แตะเพื่อเริ่ม" — เสียงดังบน iPad/iPhone
- ✅ เสียงพูดใช้ Web Speech API (ยังไม่ต้องมีไฟล์ mp3)
- ✅ เสียงเอฟเฟกต์สังเคราะห์ด้วย WebAudio (ยังไม่ต้องมีไฟล์เสียง)
- ✅ ภาพใช้ emoji (ยังไม่ต้องวาดรูป) — เปลี่ยนเป็นภาพจริงทีหลังได้โดยไม่ต้องแก้โค้ด
- ✅ Smart Review — คำที่ตอบผิดบ่อยจะกลับมาบ่อยขึ้น
- ✅ localStorage แบบหลายโปรไฟล์ (โครงสร้างพร้อม รองรับเพิ่มโปรไฟล์ทีหลัง)
- ✅ ไม่มี timer · ไม่มีคำว่า "ผิด" · ไม่มีการหักดาว
- ✅ ปุ่ม 🏠 ทุกหน้า · ปุ่ม Back ของเบราว์เซอร์ใช้ได้
- ✅ รองรับ `prefers-reduced-motion`

## รันในเครื่อง

ดับเบิลคลิก `index.html` ได้เลย (ข้อมูลอยู่ในไฟล์ `.js` จึงไม่ติดข้อจำกัด `file://`)

หรือถ้าอยากรันผ่านเซิร์ฟเวอร์:

```bash
python3 -m http.server 8080
# เปิด http://localhost:8080
```

## โครงสร้างไฟล์

```
index.html                 เกมทั้งหมด (single page)
_headers                   HTTP headers สำหรับ Cloudflare Pages
data/animals.js            คำศัพท์หมวดสัตว์ + คำพูดของ Bunny
data/packs.js              คลังคำเสริม: ผลไม้ ผัก ยานพาหนะ ของใช้ในบ้าน สี ตัวเลข
assets/css/style.css       ธีม สี ฟอนต์ animation
assets/css/games.css       สไตล์ของเกมเสริมทั้งหมด
assets/js/app.js           แกนกลาง: เสียง, router, สถานะ, เกมชุดแรก + window.HWA (API)
assets/js/games/           เกมละ 1 ไฟล์ (ดูตารางด้านบน)
  dragkit.js               ตัวช่วย "ลากแล้ววาง" ที่ใช้นิ้วบน iPad ได้
  hub.js                   หน้า "เลือกเกม"
uploads/                   โปสเตอร์คำศัพท์ต้นฉบับ (ไม่เข้า git — ใช้เป็นภาพอ้างอิง)
happy-word-adventure-concept.md   สเปกฉบับเต็ม (Concept v2)
```

### เพิ่มเกมใหม่

1. สร้าง `assets/js/games/<ชื่อเกม>.js` แล้วเขียน `window.HWA.Screens.<ชื่อเกม> = function (params) {...}`
   (ใช้ตัวช่วยจาก `window.HWA` เช่น `el`, `btn`, `speak`, `sfx`, `addStars`, `finishBox`)
2. เติมหนึ่งบรรทัดใน `LIST` ของ `assets/js/games/hub.js`
3. ต่อ `<script>` ใน `index.html`

ไม่ต้องแก้ `app.js` เลย

## เพิ่มคำศัพท์

แก้ `data/animals.js` เติมใน `words[]`:

```js
{ id: "bear", english: "Bear", thai: "หมี", emoji: "🐻",
  sentence: "This is a bear.", difficulty: 2 }
```

## อัปเกรดเป็นภาพและเสียงจริง

เพิ่ม field `image` และ `audio` ในข้อมูลคำ โค้ดจะเลือกใช้ให้เองโดยอัตโนมัติ
