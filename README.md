# 🐰 Happy Word Adventure

เว็บเกมเรียนคำศัพท์ภาษาอังกฤษแบบ **เล่นเพลิน** สำหรับเด็กอายุ 4–5 ปี
Static site ล้วน — ไม่มีฐานข้อมูล ไม่มี backend ไม่ต้อง build

**เล่นได้ที่:** _(ใส่ URL หลัง deploy)_

---

## สิ่งที่มีในเวอร์ชันนี้ (สัปดาห์ที่ 1)

| โหมด | รายละเอียด |
|---|---|
| 🎪 **เล่นเพลิน** | แตะสัตว์ → กระโดด/ส่ายหัว/หมุน + ออกเสียงชื่อ · แตะค้างพูดเป็นประโยค · ไม่มีคำถาม ไม่มีถูกผิด |
| 📖 **การ์ดคำศัพท์** | เรียนทีละ 3 คำ · ฟังซ้ำได้ไม่จำกัด · ย้อนกลับได้ |
| 🎮 **เกมทายรูป** | 5 ข้อ พร้อม **No-Fail System** — ตอบผิดได้ไม่จำกัด ระบบค่อย ๆ ช่วยจนถูก |
| 🎉 **หน้าสรุป** | ดาวขึ้นทีละดวง + confetti + ปลดล็อกสัตว์ |
| 🏡 **สวนสัตว์** | ดูสัตว์ที่สะสมได้ แตะฟังเสียงซ้ำ |

**เทคนิคที่ใส่ไว้แล้ว**

- ✅ ปลดล็อก AudioContext ด้วยหน้า "แตะเพื่อเริ่ม" — เสียงดังบน iPad/iPhone
- ✅ เสียงพูดใช้ Web Speech API (ยังไม่ต้องมีไฟล์ mp3)
- ✅ เสียงเอฟเฟกต์สังเคราะห์ด้วย WebAudio (ยังไม่ต้องมีไฟล์เสียง)
- ✅ ภาพใช้ emoji (ยังไม่ต้องวาดรูป) — เปลี่ยนเป็นภาพจริงทีหลังได้โดยไม่ต้องแก้โค้ด
- ✅ Smart Review — คำที่ตอบผิดบ่อยจะกลับมาบ่อยขึ้น
- ✅ localStorage แบบหลายโปรไฟล์ (โครงสร้างพร้อม รองรับเพิ่มโปรไฟล์ทีหลัง)
- ✅ ไม่มี timer · ไม่มีคำว่า "ผิด" · ไม่มีการหักดาว
- ✅ ปุ่ม 🏠 ทุกหน้า · ปุ่ม Back ของเบราว์เซอร์ใช้ได้
- ✅ รองรับ `prefers-reduced-motion`

## รันในเครื่อง

ดับเบิลคลิก `index.html` ได้เลย (ข้อมูลอยู่ในไฟล์ `.js` จึงไม่ติดข้อจำกัด `file://`)

หรือถ้าอยากรันผ่านเซิร์ฟเวอร์:

```bash
python3 -m http.server 8080
# เปิด http://localhost:8080
```

---

## โครงสร้างไฟล์

```
index.html              เกมทั้งหมด (single page)
_headers                HTTP headers สำหรับ Cloudflare Pages
data/animals.js         คำศัพท์ 10 คำ + คำพูดของ Bunny
assets/css/style.css    ธีม สี ฟอนต์ animation
assets/js/app.js        ตรรกะเกมทั้งหมด
happy-word-adventure-concept.md   สเปกฉบับเต็ม (Concept v2)
```

## เพิ่มคำศัพท์

แก้ `data/animals.js` เติมใน `words[]`:

```js
{ id: "bear", english: "Bear", thai: "หมี", emoji: "🐻",
  sentence: "This is a bear.", difficulty: 2 }
```

## อัปเกรดเป็นภาพและเสียงจริง

เพิ่ม field `image` และ `audio` ในข้อมูลคำ โค้ดจะเลือกใช้ให้เองโดยอัตโนมัติ
